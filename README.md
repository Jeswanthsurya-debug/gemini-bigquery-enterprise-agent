# gemini-enterprise-workspace-agent-or-gcp-gemini-enterprise-lab
# Enterprise Search & Workflow Automation with Gemini Enterprise

A hands-on implementation of Google Cloud **Gemini Enterprise** integrated with Google Workspace connectors (Google Drive & Google Calendar) for grounded enterprise search and AI-assisted workflows.

---

## 📌 Architecture & Features
* **Enterprise App Deployment**: Provisioned a multi-region `scientific-conferences-app` on Gemini Enterprise.
* **Identity & Authentication**: Configured Google Identity Provider (IdP) and OAuth 2.0 authorization for secure workspace access.
* **Data Stores & Connectors**: Integrated `cymbal-google-drive` and `cymbal-google-calendar` connectors to perform federated search across dynamic documents and schedule events.
* **Grounded Search Verification**: Executed natural language context queries retrieving grounded information directly from internal documents (`PlanetCon_Persephone.docx` & `Persephone_Analysis_Report.pdf`).
